Idea Title & Proposed Solution

SLIDE 2 / 6
🛑 The Problem Context
Traditional weather applications present fragmented numeric charts, lack conversational context, incur heavy geocoding API costs, and fail to provide accessible voice advisories or severe disaster alerts for non-technical or rural populations.
⚡ Our Proposed Solution: WeatherGPT
A chat-first climate intelligence platform allowing users to ask complex questions ("Will it rain in Bhopal tomorrow?", "Compare weather in Delhi and Tokyo") and receive conversational answers alongside visual dashboards.
📍 Complete Data Coverage
  • 700+ Indian Districts: Grouped by State/UT with exact lat/long coordinates.
  • 195+ World Capitals: Complete global capital city coverage.
  • Live Feeds: Temp, Feels-like, Wind, Humidity, UV Index, AQI, Sunrise/Sunset.

Technical Approach & System Architecture

SLIDE 3 / 6
⚙️ Production Tech Stack
React 18 TypeScript Vite Tailwind CSS Node.js Express TanStack Query Leaflet Maps Anthropic SDK Open-Meteo API
  • Frontend Layer: Component-driven React UI with dynamic weather gradients, mobile-first breakpoints, dark mode, and Leaflet map rendering.
  • Backend API Proxy: Node.js Express server with rate limiting (`express-rate-limit`), CORS security, and 15-minute response caching (`node-cache`).

🗣️ Web Speech API & Multimodal Input
  • Voice Input (Speech-to-Text): Native microphone voice search integration.
  • Text-to-Speech (TTS): Reads natural-language weather advisories aloud.

Feasibility & Financial Viability

SLIDE 4 / 6
💰 Zero-Cost Geocoding Innovation
Commercial geocoding APIs (e.g. Google Maps API) incur massive operational fees and strict rate limits. WeatherGPT solves this by pre-bundling latitude/longitude coordinate matrices for 700+ Indian Districts and 195+ World Capitals directly into JavaScript modules, delivering zero API cost and zero lookup latency.
⚡ Double-Layer Caching & Quota Efficiency
  • Backend Server Cache: `node-cache` (15-min TTL) cuts external API calls by >90%.
  • Frontend Client Cache: TanStack React Query maintains an in-memory stale time.
  • Free Open-Meteo API Tier: 10,000 requests/day per IP ensuring extreme financial viability.
🛡️ 100% Offline & Static Resilience
If the Express backend server is offline (e.g. static hosting on GitHub Pages or Surge), WeatherGPT automatically falls back to direct browser Open-Meteo calls and client-side AI response synthesis with zero downtime.
