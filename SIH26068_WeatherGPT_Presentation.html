🌤️ The Core Concept
WeatherGPT is a full-stack, chat-first climate assistant enabling users to ask complex natural-language questions ("Will it rain in Bhopal tomorrow?", "Compare weather in Delhi and Tokyo") and receive conversational, data-backed answers alongside interactive visual dashboards.
📍 Comprehensive Data Coverage
  • 700+ Indian Districts: Grouped by State/UT with exact lat/long coordinates.
  • 195+ World Capitals: Complete global coverage for instant search.
  • Live Weather Metrics: Temp, Feels-like, Wind, Humidity, Pressure, UV Index, Sunrise/Sunset, and 7-day trend.
🚨 Severe Weather & Alert Panel
Integrates an IMD-style Alert Engine evaluating live weather data against official warning thresholds for Heatwaves, Heavy Rainfall/Floods, Squall/Cyclones, and Severe AQI with color-coded severity:

Feasibility & Viability

SLIDE 4 / 6
💰 Zero-Cost Geocoding Architecture
Paid geocoding APIs (e.g. Google Maps API) incur high operational costs and rate limits. WeatherGPT solves this by pre-bundling a complete static dataset of 700+ Indian Districts and 195+ World Capitals with coordinate matrices, achieving zero API cost & zero geocoding latency.
⚡ High Availability & Double-Layer Caching
  • Backend Server Cache: `node-cache` (15-min TTL) reduces external weather API calls by over 90%.
  • Frontend Query Cache: TanStack React Query prevents re-fetching during tab switching.
  • API Quota Efficiency: Open-Meteo free tier provides 10,000 requests/day per IP, ensuring extreme financial viability.
🛡️ Offline & Static Resilience
WeatherGPT features an intelligent client-side fallback system. If the Express backend server is unreachable (e.g., when hosted on static platforms like GitHub Pages), the app automatically switches to direct browser API fetching and client-side AI synthesis with 100% uptime guarantee.
